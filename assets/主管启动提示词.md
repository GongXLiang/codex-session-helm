# 主管启动提示词

由用户填写后发送。已有明确目标和获批计划时直接进入对应阶段，不强制重新规划。删除不适用的字段。

```text
请使用 $session-helm，当前对话作为主管。

目标：【具体目标】
项目目录：【绝对路径】
权威计划：【绝对路径；尚无则写需规划】
执行状态：【绝对路径】
本次范围：【允许的任务或阶段】
受保护成果：【文件、版本或目录】
执行模型与思考程度：【固定模型／固定强度／沿用默认；未指定项按任务复杂度自动选择，遵守宿主覆盖限制】
自动选择范围：【允许的模型集合与强度上限；默认自动强度不超过 high，保留用户明确指定项】
推进方式：【逐任务验收后与我讨论／已确认计划内依赖满足即可继续】
侧栏组织：【主管留在组外／主管置顶；执行会话放入哪个组，默认以本轮工作流命名】
并行与嵌套：【允许并行的范围；默认仅主管派发一层，需子主管时写明范围】
运行环境：【本地／实际发现的远程环境；需要worktree时明确起点】

需要规划时先研读并提出计划，按约定确认后再执行；已有获批计划时核对后沿用。

我授权在本次确认的范围内新建独立执行对话、发送任务和补充要求，并授权这些执行对话向当前主管发送必要进度、结果和阻塞信息；按上面的选择组织本轮侧栏分组。任务卡附本次真实授权所在会话和主管ID。已有授权范围内按推进方式续接，不逐步重复询问。若本轮只做规划，请删除此授权段并写明不创建对话。

派发前核对真实文件，填写任务卡及 Context；回报采用短通知＋完整文件。分别登记创建、简报送达、回合结束、报告就绪和主管验收；对重复或旧版回报去重。主管独立验收，按已登记的决策门与推进方式决定后续安排，并维护计划和执行状态。需要fork、交接、解除关联或归档时按本轮实际授权处理；没有可靠自动回报能力时说明手动续接方法。
```

口头调用也可表述为：“使用 SessionHelm（会话领航），读取【项目】的计划与状态，这次只做【任务】。我授权创建独立执行对话并回报。完成后由主管验收，按【推进方式】继续。”

自然语言用于识别任务，实际跨会话操作仍须符合真实授权和工具能力。若技能未被自动识别，显式选择本 Skill 或提供其 SKILL.md 路径。
