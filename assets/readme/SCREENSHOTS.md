# 桌面演示截图

2026-11-11，Windows，窗口显示名 ChatGPT，界面处于 Codex 模式。截图来自真实运行的 SessionHelm 专用公开演示：一个置顶主管、一个执行分组、两个独立执行会话。

- `desktop-demo.png`：同一帧中侧栏与主管验收回报的两个局部并排。只裁切并安排位置，未重绘、替换或改写界面文字。透明间距用于区分两个局部，不代表原窗口的布局比例。
- `supervisor-review.png`：桌面展示图右侧的原尺寸验收回报局部。
- `executor-report.png`：T01 执行会话的连续局部，包含来自另一个聊天的任务及实际完成回报。它保留执行时的“待主管验收”状态，主管随后已完成验收。

T01 检查示例正文中“执行者回报完成，就意味着主管已经验收通过。”的状态矛盾；T02 检查示例清单中遗漏的主管验收步骤。两份报告返回后，主管核对输入与建议并分别验收；输入保持原样。

这些截图中的两项任务与 `examples/demo-state.json` 的五项静态任务示例是两个独立案例。三张桌面截图均未使用生成式图像，也未交给生图模型修改。会话 ID、私人目录和无关项目不随截图公开。

## README 插图

- `hero-en.jpg` / `hero-zh.jpg`：Opus 5.5 Medium 提出「石墨调度台」设计方向，GPT 内置生图工具生成无字纸质静物，随后用 SVG 排版中英文标题。它们是品牌插图，不是产品截图。
- `flow-{wide,narrow}-{en,zh}.png`：依据 `examples/demo-state.json` 手工构建的技术插图。文档物件采用 Visualize 技术插图指南的斜轴投影与外置标签；依赖线由示例状态生成。实线代表已验收上游，虚线代表仍待验收的上游。
- `source/` 保留无字底图、完整生图提示词、SVG 排版与 HTML 导出源。SVG 内底图使用相对路径，因此 README 嵌入已导出的 PNG，而不是含外部图片的 SVG。

中英文头图共用同一张生成底图；流程图提供宽、窄两种布局，使用 `picture` 的媒体查询切换。所有图都是静态资产，不代表实时会话状态。
