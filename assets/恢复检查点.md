# 恢复检查点

适用于停止、应用重启、主管交接或长任务续接。按需填写，保存在项目允许的目录，勿把真实会话和进程信息放进公开 Skill 示例。

```text
记录时间、宿主与应用版本：
工作流／任务ID／派发版本：
当前主管threadId/hostId；执行threadId/hostId/turnId：
真实人类授权定位与剩余范围：
权威状态、任务卡、最新报告及主管裁决路径：
输入版本、已验收结果及必要校验值：
已完成的最后一个可核对步骤：
未完成步骤与下一安全动作：
输出范围、临时文件及尚未完成的写入：
本任务拥有的进程PID、创建时间、可执行文件及用途：
最后处理事件ID、报告版本、wait cursor、尚未确认送达的消息：
正在等待的依赖和仍不得放行的后继：
停止／重启前实际运行状态；恢复后的复核证据：
```

不得仅凭相同 PID 结束进程：创建时间和用途也要匹配。恢复优先检查已有产物，不重复运行已有效验收步骤。记录不确定项，必要时先查证再继续。
