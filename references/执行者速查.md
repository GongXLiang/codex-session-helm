# 执行者速查

只读当前任务卡、项目规则、绑定文件及卡指定原件；不加载主管全局账本或其他项目报告。先确认本轮输入、输出、允许写入范围和验收。保留用户修改和已验收原件。

卡中的绑定必须来自原生派发之后的真实回执；缺失时先回报，不猜任务、版本或 attempt。执行者不写共享 SQLite。

```sh
python PATH/helm_runtime.py publish --root PROJECT --binding BINDING --kind STARTED --summary "已核对输入，开始执行"
python PATH/helm_runtime.py publish --root PROJECT --binding BINDING --kind RESULT --summary "产物就绪，等待主管验收" --report reports/T01.md --artifact outputs/result.json
```

完整报告与关键产物先落盘、读回和自检，再发布 RESULT。实质进展可用 MILESTONE；阻塞用 BLOCKED、NEEDS_INPUT 或 NEEDS_APPROVAL；执行失败用 FAILED。不要按固定秒数制造进度事件。发布一次事件后，重发通知沿用该事件，不能重写旧证据。

完成后在本执行对话回复报告入口和实际验证结果。只有真实用户已授权跨会话回告时才另发通知；主管可直接读取原生状态和持久队列。执行完成不等于通过独立验收；等待主管的新卡或明确反馈再继续下一项。

涉及科研定义、受保护成果或复杂修订时，按需读[角色执行规范](角色执行规范.md)的执行者部分。
